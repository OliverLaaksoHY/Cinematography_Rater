# Cinematography_Rater
Sovelluksen ideana on, että käyttäjät voivat saada arvosteluja ottamilleen "postauksiin" liittyen postauksen sisällön elokuvataiteellisuuteen, jokainen postaus sisältää yhden kuvan ja tekstimuotoista tietoa esimerkiksi kuvan ottopaikasta ja tietoa kuvausolosuhteista, kuten linssistä tai valokuvausasetuksista.

Sovelluksessa:
- Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
- Käyttäjä pystyy lisäämään sovellukseen "postauksia". Lisäksi käyttäjä pystyy muokkaamaan ja poistamaan lisäämiään "postauksia".
- Käyttäjä näkee sovellukseen lisätyt "postaukset". Käyttäjä näkee sekä itse lisäämänsä että muiden käyttäjien lisäämät "postaukset".
- Käyttäjä pystyy etsimään "postauksia" hakusanalla tai muulla perusteella. Käyttäjä pystyy hakemaan sekä itse lisäämiään että muiden käyttäjien lisäämiä "postauksia".
- Sovelluksessa on käyttäjäsivut, jotka näyttävät jokaisesta käyttäjästä tilastoja ja käyttäjän lisäämät "postaukset".
- Tietokohteille on valittavissa useampia luokitteluja, jotka on tallennettu tietokantaan. Käyttäjä voi valita jokaisen luokittelun kohdalla yhden useasta vaihtoehdosta.
- Sovelluksessa on pääasiallisen "postauksien" lisäksi kommentteja. Käyttäjä pystyy lisäämään kommentteja omiin ja muiden käyttäjien "postauksiin" liittyen.
